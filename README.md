📊 Features
Real-time news analysis

98.93% accuracy

Confidence scores

Key word indicators

Mobile responsive

🛠️ Tech Stack
Backend: Flask (Python)

ML Model: Logistic Regression + TF-IDF

Frontend: HTML/CSS/JS

Hosting: PythonAnywhere (Free)
