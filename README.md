🛡️ Fake News Detector

A machine learning web app that detects fake news using Logistic Regression with TF-IDF.

🚀 Live Demo
Try it now: https://HannibalBarca.pythonanywhere.com

📊 Features
Real-time news analysis

98.93% accuracy

Confidence scores

Key word indicators

Mobile responsive

🛠️ Tech Stack
Backend: Flask (Python)

ML Model: Logistic Regression + TF-IDF

Frontend: HTML/CSS/JS

Hosting: PythonAnywhere (Free)


🏃‍♂️ Quick Start
bash
git clone https://github.com/NoumaanSeecs/fake-news-detector.git
cd fake-news-detector
pip install -r requirements.txt
python app.py

## 📚 Dataset
- **Source:** [ISOT Fake News Dataset]((https://www.kaggle.com/emineyetm/fake-news-detection-datasets))
- **Size:** 44,898 articles (50% real, 50% fake)
- **Real sources:** Reuters, BBC, etc.
- **Fake sources:** Various unreliable websites
- **Time period:** 2016-2017
- **Download:** [Kaggle Link](https://www.kaggle.com/emineyetm/fake-news-detection-datasets)
